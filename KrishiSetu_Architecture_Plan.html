1. Executive Overview

KrishiSetu is an agricultural procurement marketplace designed to connect small/medium-scale farmers directly with verified commercial buyers. This technical blueprint establishes a unified full-stack architecture combining Next.js 14 (App Router) for high-performance React rendering with Supabase for authentication, relational database storage, and real-time marketplace updates.

3. Supabase Relational Database Schema

The marketplace backend relies on 5 primary relational tables with strict Row Level Security (RLS):

Table Name Primary Key / Foreign Keys Description & Purpose
profiles id (FK → auth.users) User profile information, roles (farmer, buyer, admin), and verification status (verified, summary: pending).
listings id, farmer_id (FK → profiles.id) Crop produce listings including category, quantity (kg/quintal), asking price, APMC rate reference, and harvest date.
offers id, listing_id, buyer_id Price negotiations submitted by buyers (offered unit price, quantity, status: pending, accepted, rejected).
orders id, listing_id, buyer_id, farmer_id Confirmed purchase transactions tracking order lifecycle (pending, confirmed, picked_up, completed).
market_prices id APMC mandi reference prices and Government Minimum Support Prices (MSP) for smart price indicators.
